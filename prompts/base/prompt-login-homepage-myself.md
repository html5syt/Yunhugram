# 登录界面
整体参考telegram实现，但是有以下区别：
1. 允许用户自行切换登录方式（手机号、邮箱），并且允许用户在登录界面直接切换到注册界面。
2. 云湖在登录时有滑动验证码/图形验证码（telegram无该环节），需要参照telegram的做法优雅的处理。

# 主页
参考telegram，但是有以下区别：
1. 主页下方tab栏改为以下功能入口：（按顺序从左到右）
   1. 聊天
   2. 联系人
   3. 社区
   4. 发现
   5. 个人资料
   其中，个人资料右上角三个点左侧放置telegram原本放置在tab栏的“设置”入口。

# 聊天
整体参考telegram实现，但是有以下区别：
1. 右上角三个点中的选项需要添加云湖的部分入口：
   1. 创建机器人
2. 以下云湖的入口放到联系人中（下面会提到）
   1. 邀请微信好友
   2. 邀请QQ好友
3. 云湖中的扫描二维码入口放到个人资料中，具体参考对应开发prompt。

# 联系人
整体参考telegram实现，但是有以下区别：
1. tg的邀请朋友入口中，实现的功能从邀请通讯录好友改为上述的“邀请微信好友”和“邀请QQ好友”。
2. tg的最近通话入口去除，云湖无该api。
3. tg原有的单个联系人列表改为云湖下的折叠列表（样式自行按照tg样式处理，排序入口保留tg的做法）：
   1. 好友
   2. 我加入的聊天
   3. 机器人
