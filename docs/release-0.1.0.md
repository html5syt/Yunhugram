# Yunhugram 0.1.0

Telegram 风格的云湖客户端，Flutter 界面与 Rust 核心库。

- 手机号登录、邮箱密码登录、手机号注册，滑动和图片验证码。
- 聊天、联系人、社区、发现、个人资料五个入口。
- 对话列表、名称与对象搜索、基础文本发送和历史翻页。
- 好友、加入的聊天、机器人独立折叠，支持名称排序与添加申请。
- 微信／QQ 邀请，设置中的语言切换和退出登录。

社区、发现、资料编辑、二维码扫描和完整媒体／机器人管理尚未开放。不能显示的消息类型会明确提示，不会隐藏消息的存在。

已执行核心逻辑、跨语言调用和界面检查，并读取过真实验证码接口。尚未使用实际账号完成登录、注册、邀请和消息发送验证。

桌面安装包目前未配置商业代码签名。iOS 在自动检查中生成未签名版本，不作为可直接安装的正式包发布。

本项目不是云湖或 Telegram 官方客户端。源代码采用 GPL-2.0-or-later，第三方名称与图标权利归原权利人所有。
