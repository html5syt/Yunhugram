# Yunhugram

Telegram 风格的云湖客户端，使用 Flutter 界面和 Rust 核心库。

**当前版本：0.1.0**

- 手机号／邮箱登录，手机号注册，滑动与图片验证码。
- 对话、搜索、基础文本聊天，好友／群聊／机器人折叠列表。
- 微信／QQ 邀请，默认中文，可切换英文。
- 移动端与桌面端共用界面组件和核心库。
